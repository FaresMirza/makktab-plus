# References Required

- When investigating a topic, suggesting a tool, recommending a library, or proposing an approach — always search the web for up-to-date information first.
- Every claim, recommendation, or suggestion must include a source reference (URL) to official docs, GitHub repos, blog posts, or articles.
- Do NOT rely solely on training data. Always verify with a live web search to ensure information is current.
- If a tool or library version matters, confirm the latest version from the official source.
- Format references as a list at the end of your response:

```
**References:**
- [Title](URL)
- [Title](URL)
```

- If no reliable source is found, explicitly say so — do not fabricate links.
